## 5. Reproducibility Profile

### 5.1 Determinism Controls

- Fixed timestep value: 1 simulation tick per EngineInstance.update call; frame loop uses step-debt budgeting (not wall-clock dt normalized).
- Entity iteration order strategy: deterministic array iteration order per tick for plants/microorganisms, but order can diverge over time after filtered removals and stochastic births/deaths.
- RNG stream policy: single seeded xorshift stream via setSimulationSeed/randomFloat in utilities.
- Floating-point mode notes: standard JavaScript Number math; cross-engine/browser strict reproducibility not formally guaranteed.

## 6. Learning and Readability Notes

- Genotype to phenotype translation is centralized in RibosomeParser and then consumed by Plant/Microorganism constructors.
- Behavioral emergence combines fixed trait expression with ANN outputs and local environment cues.
- Common pitfall: interpreting seeded RNG as strict determinism without controlling update order and measurable replay harnesses.
- Common pitfall: hardcoded ecology constants in class statics can silently drift from blueprint parameter registry.
